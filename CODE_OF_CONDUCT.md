# Code of Conduct

## The short version

Be decent. Assume the person on the other side is acting in good faith until
they show you otherwise.

## What is expected

- Criticise the code, not the person who wrote it.
- Say what you mean plainly. Directness is welcome; contempt is not.
- Accept that "no" is a complete answer to a feature request, and that a
  maintainer's time is not owed to anyone.
- If you are wrong, say so and move on. Nobody here has to defend a position
  they no longer hold.

## What is not

- Harassment, insults, or sustained personal hostility, in issues, pull
  requests, commit messages or anywhere else this project is discussed.
- Publishing someone's private information.
- Sexualised language or imagery, and unwelcome attention of that kind.
- Deliberately wasting people's time: bad-faith arguments, repeated demands for
  free work, or reopening settled decisions without new information.

## Security reports are different

This is a security tool, and a vulnerability report is not a normal issue. It
has its own channel and its own rules — see [SECURITY.md](SECURITY.md). Do not
post one publicly, and do not use this document as a lever to get one triaged
faster.

## Scope

This applies in the project's own spaces: issues, pull requests, discussions and
commit history. It does not extend to what contributors do elsewhere, with one
exception — conduct elsewhere that is directed at someone *because of* their
participation here is in scope.

## Enforcement

Report a problem to **info@simplixio.net**. Reports go to the maintainer, and
what you send stays private.

There is no committee and no appeals process; this is a small project and
pretending otherwise would be theatre. Expect one of: a private word, a request
to edit or withdraw something, a temporary block, or a permanent one. The
maintainer will say which and why.

The maintainer is not exempt from any of the above.

## Attribution

This is written for this project rather than adapted from a template, so that
the enforcement section describes what will actually happen rather than a
process that does not exist here.
